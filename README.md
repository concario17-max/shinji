# 다카하시 신지(高橋信次) 강연 한글 번역 동영상 웹사이트

마우스 휠을 내릴 때 연속해서 펼쳐지는 **다크 미니멀 글래스모피즘 카드 피드** 스타일의 26편 강연 아카이브 웹사이트입니다.

## 🌟 주요 특징

1. **감각적인 다크 테마 디자인**: 딥 버건디/보라 앰비언트 그라데이션 및 유리가 비치는 듯한 입체적 카드 디자인.
2. **연속 스크롤 그리드 피드 (Continuous Scroll Feed)**: 26편의 강연이 시원한 3~4열 그리드로배치되며 마우스 휠 스크롤 시 부드럽게 추가 렌더링됩니다.
3. **상세 팝업 모달 플레이어**:
   - 카드를 클릭하면 영상 재생 창이 팝업으로 뜹니다.
   - 우측에 **한국어 번역 강의록 / 요약문** 및 **타임스탬프 목차**를 제공합니다.
   - 타임스탬프 클릭 시 영상의 해당 위치(시간)로 즉시 이동합니다.
4. **실시간 검색 및 카테고리 필터링**: `노래`, `DVD`, `CD` 탭 및 검색어 입력 기능 지원.

## 🛠️ 내 영상 주소(유튜브 링크)로 변경하는 방법

`j:\홈페이지\shinji\js\lectures-data.js` 파일을 열고 각 강의의 `youtubeId` 속성을 본인의 유튜브 영상 ID로 바꿔주시면 됩니다.

예시:
유튜브 링크가 `https://www.youtube.com/watch?v=ABC123xyz` 인 경우:
```javascript
{
  id: 1,
  number: "#01",
  title: "마음의 원리와 인간의 본질",
  youtubeId: "ABC123xyz", // <- 본인 유튜브 ID 입력
  ...
}
```
