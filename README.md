# 다카하시 신지(高橋信次) 이야기 236편 & 강연 동영상 통합 웹 아카이브

다카하시 신지의 236편 한국어 충실번역 이야기(5개 장 구성)와 요약 만화 카드, 그리고 47편의 강연 동영상을 담은 **다크 글래스모피즘 웹 포털**입니다.

---

## 🌟 주요 구성 및 특징

### 1. 📖 다카하시 신지 이야기 (001~236편 완역 & 5개 장 체계)
5개 장으로 정밀하게 분류되어 있으며, 각 편마다 **요약 만화 카드(1~139)**와 **한국어 충실 번역 전문**을 1:1로 제공합니다.

| 장 | 번호 범위 | 항목 수 | 장 제목 | 핵심 흐름 |
| :--- | :---: | :---: | :--- | :--- |
| **제1장** | **001–050** | 50편 | **탄생과 전생, 그리고 참된 메시아의 출현** | 출생·가족·전생 → 어린 시절 체험 → 영적 각성 → 신지의 사명과 정법 |
| **제2장** | **051–100** | 50편 | **영혼의 세계와 정법의 실천** | 영혼·수호령·지도령 → 윤회 → 빙의·영적 현상 → 마음과 생활의 조화 |
| **제3장** | **101–150** | 50편 | **마음의 본질과 인간의 목적·사명** | 마음의 구조 → 신리와 과학 → 인간의 목적 → 윤회와 사명 → 사후세계와 현증 |
| **제4장** | **151–200** | 50편 | **정법의 전개와 삶에서 드러나는 현증** | 정법의 유전 → 사회·종교 비판 → 다양한 체험·현증 → 인생의 의미와 실천 |
| **제5장** | **201–236** | 36편 | **신리의 완성과 인류·지구의 미래** | 새로운 부활 → 태양계의 천사들 → 지구와 인류 → 신리의 궁극적 방향 → 마지막 기록 |

* **하이브리드 모달 뷰어**: `🖼️ 요약 만화`, `📄 충실 번역 전문`, `📑 양쪽 함께 보기(Split)` 3가지 보기 모드 지원.
* **만화 전체화면 라이트박스**: 클릭 시 고화질 원본 만화 컷 확대 보기 지원.
* **단축키 이동**: 키보드 `←`(이전화), `→`(다음화), `Esc`(닫기) 지원.

### 2. 🎬 강연 동영상 아카이브 (총 47편)
* 노래(마음의 찬가 등), DVD 강연 시리즈(DVD-01 ~ DVD-18 전편), CD 음성 강연.
* **타임스탬프 목차**: 클릭 시 영상의 해당 재생 시간으로 즉시 이동.
* **실시간 검색 및 카테고리 필터링**: `노래`, `DVD`, `CD` 필터 지원.

## 🎨 만화 이미지(140.png ~ 236.png) 추가하는 방법

새로운 만화 이미지 카드가 완성되면 아래 폴더에 파일명 형식(`140.png`, `141.png`, ...)대로 넣어주시면 됩니다.

1. `images/stories/` 폴더에 `140.png`, `141.png` 등을 복사합니다.
2. 터미널에서 아래 자동 파서 명령어를 실행합니다:
   ```bash
   python scripts/extract_stories.py
   ```
3. 자동으로 `js/stories-data.js`가 업데이트되어 새 만화 카드가 웹사이트에 바로 표시됩니다.

## 🛠️ 내 유튜브 영상 ID로 변경하는 방법

`js/lectures-data.js` 파일을 열고 각 강의의 `youtubeId` 속성을 본인의 유튜브 영상 ID로 바꿔주시면 됩니다.

```javascript
{
  id: 1,
  number: "#01",
  title: "마음의 원리와 인간의 본질",
  youtubeId: "ABC123xyz", // <- 본인 유튜브 ID 입력
  ...
}
```

## 🚀 실행 및 배포 방법
